## You're here because…

You're consulting on EU AI Act readiness and you need a tool that produces *machine-readable* evidence for Annex IV / Annex V, not another GRC dashboard. Earlier versions of these docs conflated cryptographic integrity with regulatory conformity. This page separates them: a signed VC proves an artefact existed and wasn't tampered with; it does **not** replace the conformity assessment itself, or notified-body sign-off where Article 43 requires one.

## 60-second install

```bash
pip install attestix
```

## First 30 lines that actually do something

```python
from attestix.services.identity_service import IdentityService
from attestix.services.provenance_service import ProvenanceService
from attestix.services.compliance_service import ComplianceService
from attestix.services.credential_service import CredentialService

agent_id = IdentityService().create_identity(
    display_name="client-hr-screener",
    source_protocol="manual",
    capabilities=["cv_screening", "candidate_ranking"],
    issuer_name="Client Co. (assessed by VibeTensor)",
)["agent_id"]

ProvenanceService().record_training_data(
    agent_id=agent_id,
    dataset_name="Client historical hiring records 2020-2024",
    source_url="internal://client/hr",
    license="Proprietary",
    data_categories=["employment", "demographics"],
    contains_personal_data=True,
    data_governance_measures="Removed protected attributes per Art. 10(2)(f). Bias audit Q4-2025.",
)

# Annex III point 4(a): employment / CV screening = high-risk
ComplianceService().create_compliance_profile(
    agent_id=agent_id,
    risk_category="high",
    provider_name="Client Co.",
    intended_purpose="Initial CV screening with human reviewer in the loop.",
    human_oversight_measures="Recruiter reviews shortlist; no automated rejection.",
    transparency_obligations="Candidates informed that a high-risk AI system assists screening (Art. 26(11)).",
    annex_iii_category=4,
)

# Article 43(2): Annex III points 2-8 use internal control (Annex VI), so the
# provider's own assessment is the conformity assessment here. (Annex III point 1,
# biometrics, needs a notified body when harmonised standards are not applied;
# Annex I products follow their sectoral procedure.)
ComplianceService().record_conformity_assessment(
    agent_id=agent_id,
    assessment_type="self",
    assessor_name="Client Co. conformity team (Annex VI internal control)",
    result="pass",
    findings="Chapter III, Section 2 requirements met; human oversight documented.",
    ce_marking_eligible=True,
)

declaration = ComplianceService().generate_declaration_of_conformity(agent_id)
print(declaration["declaration_id"])  # signed Annex V document id
```

## What you just got

- The start of an Annex IV-shaped evidence set (identity + training data + compliance profile + conformity assessment), each record signed with the server's Ed25519 key. Add `record_model_lineage` and `log_action` calls to cover model lineage and the Article 12 trail.
- A signed Annex V Declaration of Conformity, issued only after a passing conformity assessment row exists. The service accepts a `self` assessment for Annex III points 2-8 (when `annex_iii_category` is set) and requires `third_party` for point 1 or when no category is set.
- A path to bundle the evidence into a W3C Verifiable Presentation for the regulator:

```python
vp = CredentialService().create_verifiable_presentation(
    agent_id=agent_id,
    credential_ids=[declaration["credential_id"]],
    audience_did="did:web:eu.regulator",
    challenge="ch_audit_2026",
)
```

## What this does NOT prove

Read this section before billing a client. It is the single most important distinction in the product.

| Attestix proves… | Attestix does NOT prove |
|---|---|
| The declaration existed at this hash | A notified body has approved CE marking |
| The conformity assessment row was recorded by this issuer DID | The assessor's findings are factually sound |
| The audit trail is internally consistent (hash chain unbroken) | The agent's actual behaviour matched the declared purpose |
| The signing key controlled by this issuer signed the artefact | Legal liability has shifted from provider to anyone else |

Provider liability under Articles 16 to 22 stays with the provider regardless of what Attestix outputs. See the [EU compliance walkthrough](/docs/guides/eu-compliance-walkthrough) for the full mapping.

## Next step (5 minutes)

Pull the full hash-chained Article 12 trail for the client's audit binder. `attestix audit` prints human-readable text (and a chain-integrity check), not JSON:

```bash
attestix audit <agent_id> --limit 500 > client-audit-2026.txt
```

For machine-readable rows, use Python:

```python
import json
from attestix.services.provenance_service import ProvenanceService
rows = ProvenanceService().get_audit_trail(agent_id, limit=500)  # default limit is 50
json.dump(rows, open("client-audit-2026.json", "w"), indent=2)
```

Inspect the chained provenance bundle (training data + model lineage + audit log) for the binder:

```python
from attestix.services.provenance_service import ProvenanceService
bundle = ProvenanceService().get_provenance(agent_id)
print(bundle["audit_log_count"], "audit rows;",
      len(bundle.get("training_data", [])), "datasets")
```

Each row in `get_audit_trail(agent_id)` carries `prev_hash` and `chain_hash` fields, so a third party can re-derive the chain offline without contacting Attestix: `chain_hash` is SHA-256 of `prev_hash + ":" + ` the row serialised as sorted, compact JSON with only `chain_hash` and `signature` removed (`prev_hash` stays in).

If you want an on-ledger commitment so the client can prove the bundle existed at a block height, add a Base L2 anchor. This needs `pip install 'attestix[blockchain]'` and a funded wallet key in `EVM_PRIVATE_KEY`; it uses **Sepolia testnet** by default (`BASE_NETWORK=mainnet` for mainnet). An anchor proves a hash existed at a block height; it is **not** a legal non-repudiation guarantee:

```python
from attestix.services.blockchain_service import BlockchainService
print(BlockchainService().anchor_audit_batch(agent_id=agent_id))
```
