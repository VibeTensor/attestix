## You're here because…

You're a solo or small-team dev shipping a LangChain agent and you don't have time to hand-roll an audit trail before launch. The "5-minute promise" used to break at the import step: `from services.identity_service import ...` only worked from a cloned repo, not from a clean `pip install`. Since v0.4.0 the package ships the canonical `attestix.*` namespace, so the snippet below runs end-to-end from a fresh venv.

## 60-second install

```bash
pip install 'attestix[langchain]' langchain-openai
```

That installs v0.4.1 plus `langchain-core` (the `[langchain]` extra) and the OpenAI chat model used below. The extra does not install the full `langchain` package; the snippet only needs `langchain-core`.

## First 30 lines that actually do something

```python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import PromptTemplate
from langchain_openai import ChatOpenAI
from attestix.integrations.langchain import AttestixCallback
from attestix.services.identity_service import IdentityService

# 1. One-time: create the agent identity (signed with the server key, persisted to
#    ~/.attestix/identities.json). Save agent["agent_id"] and reuse it on later runs;
#    calling create_identity again creates a new identity.
agent = IdentityService().create_identity(
    display_name="rag-helper",
    source_protocol="manual",
    capabilities=["retrieval", "synthesis"],
    issuer_name="VibeTensor",
    expiry_days=365,
)

# 2. Wire the callback. Every tool call, LLM call, and chain step gets
#    SHA-256 hash-chained, signed with the server's Ed25519 key, and stored locally.
callback = AttestixCallback(
    agent_id=agent["agent_id"],
    record_llm_tokens=True,
    issue_vc_on_success=True,  # default True
)

llm = ChatOpenAI(model="gpt-4o-mini")
prompt = PromptTemplate.from_template("Answer briefly: {input}")
chain = prompt | llm | StrOutputParser()

result = chain.invoke(
    {"input": "Summarise our Q4 board pack."},
    config={"callbacks": [callback]},
)
print(result)
```

## What you just got

- A row in the local hash-chained audit trail for each LLM, tool, and chain start/end event (`on_llm_start`, `on_llm_end`, `on_tool_start`, `on_tool_end`, `on_chain_start`, `on_chain_end`).
- A signed `ChainExecutionCredential` (claims: `events_logged`, `framework`) issued on each `on_chain_end`, which includes nested chain steps, so one invocation can produce several. List them with `attestix credential --list --agent-id <agent_id>` and check one against the local store with `attestix credential --verify-cred <cred_id>`.
- A persistent `agent_id` you can reuse across runs. The DID on the identity is the Attestix server's `did:key`; agents do not get their own keypair.

Verify the chain hashes still line up:

```bash
attestix audit <agent_id>
```

The deeper [LangChain integration guide](/docs/guides/langchain) covers the callback options in more detail.

## Next step (5 minutes)

Anchor today's audit batch to **Base L2 testnet** (Sepolia). This needs the blockchain extra (`pip install 'attestix[blockchain]'`) and a wallet funded with Sepolia test ETH whose key is in `EVM_PRIVATE_KEY`:

```python
from attestix.services.blockchain_service import BlockchainService

anchor = BlockchainService().anchor_audit_batch(agent_id=agent["agent_id"])
print(anchor.get("error") or anchor["explorer_url"])  # https://sepolia.basescan.org/tx/0x...
```

Sepolia is the default; set `BASE_NETWORK=mainnet` to anchor on Base mainnet with real funds. Either way, an anchor proves a hash existed at a point in time; it is **not** a legal non-repudiation guarantee. See the [Base L2 anchor walkthrough](/docs/guides/base-l2-anchor) for the full setup.
